# preact on bun

Пример preact на bun для Timeweb Cloud Apps.

## Параметры деплоя

| Параметр | Значение |
| --- | --- |
| Runtime | `bun` |
| Фреймворк в API | `preact` |
| Тип приложения | `frontend` |
| Команда сборки | `bun run build` |
| Директория сборки | `dist` |

## Локальный запуск

```bash
bun install
bun run build
```
